## Getting Started

### Prerequisites
- Node.js (v16+ recommended)
- npm (v8+ recommended)

### Installation
```bash
git clone https://github.com/dineshjadeja08/cavve.git
cd cavve
npm install
```

### Running Locally
```bash
npm start
```
By default, the app runs at `http://localhost:3000`.

### Running Tests
```bash
npm test
```
